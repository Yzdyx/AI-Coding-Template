# Support

## Get help

Start with the repository's own evidence:

1. Read [README.md](README.md) for setup and template boundaries.
2. Open [docs/index.md](docs/index.md) and choose the task-specific route.
3. Search [docs/repository-map.md](docs/repository-map.md) for the path's owner
   and purpose.
4. Read the affected module's `README.md` and nested `AGENTS.md`.

If the answer is not present, use the repository issue forms:

- [Report a bug](https://github.com/Yzdyx/AI-Coding-Template/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/Yzdyx/AI-Coding-Template/issues/new?template=feature_request.yml)

Include the tested commit, operating system, Python/Node/pnpm versions, commands,
actual output, expected behavior, and the smallest reproducible example.
Remove secrets, tokens, credentials, private URLs, and customer data.

## Security

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md) instead.

## Support boundary

This repository is a template and reference implementation. It does not provide
a deployed service, production on-call, or a response-time guarantee. Issues are
handled on a best-effort basis, and examples may be intentionally incomplete.

Questions about a repository created with **Use this template** belong in that
new repository's support channels, not in this template's issue tracker unless
the defect can be reproduced here.

## Status vocabulary

Use these words consistently in every surface.

| Status | Label | Tone |
| --- | --- | --- |
| running | Running | neutral |
| awaiting_approval | Waiting for approval | warning |
| degraded | Degraded | warning |
| succeeded | Succeeded | positive |
| failed | Failed | danger |
| cancelled | Cancelled | muted |

A degraded result is never rendered as a complete result.

## Layout rules

1. One primary action per screen.
2. A destructive action is separated from the primary action and requires confirmation.
3. Status is conveyed by text, not by color alone.
4. Tables show at most 8 columns; overflow moves into a detail view.

## Accessibility

- Contrast ratio of at least 4.5:1 for body text.
- Every interactive control is keyboard reachable.
- Every asynchronous action announces its result to assistive technology.
